# SUGUMA

Plateforme de services numériques au Burkina Faso, appelée à évoluer progressivement.

## Nos applications

- client/ : application destinée aux clients.
- gestion/ : application privée de gestion.

## Backend

Supabase : base de données commune aux deux applications.

## Objectif

Créer deux applications indépendantes, sécurisées et connectées.
